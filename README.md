# 制造与贸易集团 ERP

面向有独立制造和贸易法人的团队。把销售分批、物料计划、采购、批次库存、生产与委外、质量和财务接到同一条单据链。每个法人保留独立库存和账簿，跨法人调拨成对过账。

PHP 8.2+ · MySQL 8.4 · Apache-2.0

## 快速开始

使用 Docker Compose v2，从空库安装。复制 `.env.example` 为 `.env`，填写两个不同的数据库密码 `ERP_DB_PASSWORD` 和 `ERP_MYSQL_ROOT_PASSWORD`。

```sh
docker compose up -d --build
docker compose ps -a
curl --fail http://127.0.0.1:8080/health.php
```

`migrate` 首次运行后正常退出，Web 和后台进程在迁移成功后启动。健康检查就绪后，在独立演示环境执行：

```sh
docker compose exec web sh
export ERP_DEMO_PASSWORD
printf '演示密码（12 至 72 字节） '
stty -echo; read -r ERP_DEMO_PASSWORD; stty echo; printf '\n'
php bin/erp.php demo
unset ERP_DEMO_PASSWORD
exit
```

打开 [本地工作台](http://127.0.0.1:8080/)，用 `admin@factory.example.test` 和上一步的密码登录。演示命令用同一邮箱再次执行时返回原场景，保留原有单据和回执。正式账套可使用 CLI 创建初始集团和管理员，再通过工作台添加法人、岗位和主数据。[本机安装与运维](docs/deployment.md)

## 公开演示

一家制造法人和一家贸易法人共用集团物料编码。计划员为 100 台设备展开两级 BOM，采购确认在途，车间使用批准的替代料，质检放行 98 台并为剩余 2 台生成返工单。

| 验算项 | 结果 |
| --- | --- |
| 采购净需求 | 需求 200 件，现货 70 件，按期在途 30 件，净缺 100 件 |
| 替代料成本 | 10 件，每件多 2 元，合计多 20 元 |
| 首批交付 | 98 台已出库，2 台仍在关联返工单 |
| 批次谱系 | 从替代料批次追到设备批次、发货单和合成客户 |

登录首页后，四张结果卡分别进入试算、工单、出库及返工记录。核对工单的替代料领用和费用，再进入批次库存下载追溯 CSV。财务页面可以查看对应的应收、应付与凭证。

## 业务范围

| 业务域 | 三项核心能力 |
| --- | --- |
| 组织与主数据 | F01 集团和法人账套、部门与岗位授权。F02 集团物料、组织供应策略与标准价。F03 单位换算生效版本和交易快照。 |
| 销售与承诺 | F04 销售订单。F05 分批交期、分配和部分发货。F06 冻结需求、取消和下游处置。 |
| BOM 与工艺 | F07 多级 BOM、损耗和循环引用检查。F08 替代料及领用授权。F09 工艺路线、标准工时和工单快照。 |
| 物料计划 | F10 按需用日计算净需求。F11 供需来源、重算差异和历史。F12 采购、生产、委外建议及后续单据。 |
| 采购与仓储 | F13 询价、报价、定标与采购单。F14 按单位换算分批收货和待检库存。F15 库位流水、批次查询和谱系导出。 |
| 车间与委外 | F16 机台班次、有限产能排程和工时实绩。F17 工单领退料、超领控制和用料核对。F18 委外发料、回收、报损和加工费匹配。 |
| 质检与交货 | F19 完工报检和版本化判定。F20 部分放行、拒收及关联返工。F21 成品预留、交付和客户追溯。 |
| 成本与业财 | F22 材料、人工、费用与实际完工成本。F23 发票匹配、应收应付和核销。F24 往来配对、总账与月结快照。 |

计划员和仓储岗位可用后台任务导入物料、BOM 或期初数据。每行保留输入、执行人和结果，失败行可修正重试。仓储可按外部来源和回执号跟踪未到的收货，登记后任务关联原采购单和实际收货单。导出支持领料、批次谱系、成本差异、应收、应付和会计凭证。
