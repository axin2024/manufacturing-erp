# BOM 导入、检验规则和成本分摊

## BOM 批量导入格式 1

在「批量任务」选择「物料清单导入」，提交一个 JSON 数组。先在同一账套登记父件、组件、替代料及所需单位换算。

```json
[
  {
    "product_code": "DEVICE",
    "effective_on": "2038-06-01",
    "lines": [
      {
        "item_code": "PIN",
        "quantity": "2",
        "uom": "ea",
        "loss_bps": 0,
        "alternative_codes": ["PIN-ALT"]
      }
    ]
  }
]
```

计划岗位可以提交。每行发布一个完整 BOM，每个 BOM 最多 100 个组件，每个组件最多 12 种替代料。用量按 `uom` 指定的单位表示，最多三位小数。损耗率以基点登记，例如 125 表示 1.25%。循环依赖、重复生效日期或物料范围错误会保存在该行回执中，其他行继续处理。

同一法人、同一操作的请求标识只分配给一次提交。由原提交人用相同内容重试可取得同一任务号。工作进程逐行提交，页面列出待处理、已成功、已拒绝、可重试及已取消的行。重试时可以逐行改正输入。取消只影响尚未开始的行。已发布版本继续有效。

## 自托管规则文件格式 1

把 [示例规则文件](../examples/extensions.php) 复制到站点文档根目录之外。把文件绝对路径设置为 `ERP_EXTENSIONS_FILE`，在提供 HTTP 和运行工作进程的环境中分发同一文件。规则文件由部署方作为 PHP 源码安装，并随应用进程执行。变更规则代码时使用新的标识，如 `certificate-reference-v2`。仍有进行中记录时继续安装旧版本。

| 键 | 格式 |
|---|---|
| `format_version` | 整数 `1` |
| `quality_for_new_cases` | 可选。将 `purchase`、`work`、`subcontract` 的任意来源映射到各自的规则版本 |
| `quality_rules` | 版本标识到检验闭包的映射 |
| `allocation_for_new_work` | 可选。新建自制或返工单使用的分摊版本 |
| `cost_policies` | 版本标识到成本分摊闭包的映射 |

版本标识使用小写 ASCII 字符并以正整数版本号结尾。未配置时，检验和分摊分别使用内置的 `erp-inspection-v1` 和 `erp-quantity-v1`。可停止为新记录选用旧规则，同时保留映射供现有对象处理。启动后，可用 `php bin/erp.php health` 检查迁移状态和启用的规则配置。

### 检验规则

闭包接收两个数组。检验单提供 `case_id`、`org_id`、`source_kind`、`item_code`、`lot_code`、`pending_milli`、`version`。判定输入提供 `accepted_milli`、`rejected_milli`、`rework_milli`、`measured_on` 和 `reason`。允许通过时返回 `null`，拒绝时返回一条可向操作员展示的原因，最长 255 字节。

检验单生成时固定规则版本。只有检验岗位可以提交判定，提交时仍校验待检数量和并发版本。规则拒绝返回 HTTP 422，缺少固定版本返回 503。失败时库存与检验版本保持不变，可以补充依据后重试。已成功的请求重放原回执。

### 工单分摊

闭包依次接收人工与制造费用总额、本次完工后的累计数量及工单总数量。金额是整数分，数量是千分之一基础单位。返回累计应分摊的金额。工作进程从持久数据取上次累计金额，以本次累计减去上次累计得到本批应分摊额。累计金额须递增或持平，全部完工时必须等于费用总额。材料按实际领用成本归集，委外按发料、回收和加工费规则处理。

自制和返工单在创建时固定分摊版本。规则遗漏费用、返回无效金额或缺少固定版本时，完工过账返回 503。投入消耗、库存、成本和回执在同一事务里回滚。恢复版本后，原经办人可以重试。成功过账的批次保留原值，修正按开放期间的业务调整流程处理。

规则实现应只计算或校验输入。一次操作失败后可能使用同一输入再次调用，规则不得自行写数据库或调用外部服务。贡献规则时，请附最小输入、数量与金额的预期答案，以及使用旧版本读取或完成历史记录的验收步骤。

## 回归

在已迁移的可丢弃数据库设置 `ERP_TEST_DATABASE=1` 后，运行 `php tests/extensions.php`。样例工单投入成本 200 分，人工与制造费用合计 400 分，两次各完工一件，实际成本分别为 400 分和 200 分。测试同时校验旧检验规则在更换默认值后继续生效，缺失规则或累计分摊回退不会产生部分过账。
