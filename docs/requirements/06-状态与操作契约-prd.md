# 制造与贸易集团 ERP｜状态与操作契约

## 生产工单的生命周期

计划建议→审核→下达→领料→完工待检→结案。缺料可挂起，返工生成关联子工单。

## 权限与操作者

销售录入订单，计划员审批计划，采购对供应商下单，车间记录耗用，质检放行批次，财务关期。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 运行 MRP 输入组织、需求截点及策略版本；输出供需关联、短缺清单和建议来源。
2. 领料提交工单、批次、实耗数量；返回库存流水与成本项，完工交付时生成批次谱系。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 组织与主数据 | 物料有基础单位与组织策略，单位换算固定在交易行，法人间移动须成对生成往来。 | 修改未来换算率不能改写历史批次。 |
| 销售与承诺 | 订单分批交货，每一行保留需求日期、已分配数量和计划来源。 | 取消已开工需求触发处置清单。 |
| BOM 与工艺 | 生效日选择物料与工序版本，发布前校验环、损耗与单位；投产工单持有版本快照。 | 循环引用拒绝发布并指出完整路径。 |
| 物料计划 | 按日期扣除可用和按期在途，冻结已确认供给，重算保存差异供计划员接受。 | 晚于需求日的到货单不能冲抵本期缺口。 |
| 采购与仓储 | 采购行关联短缺建议；合格、拒收和待检分账；批次移动生成流水。 | 重复收货回执不会增加可用量。 |
| 车间与委外 | 设备班次限制排程，领用替代料需批准，委外供料跟踪加工方结存与损耗。 | 多领物料须补授权，委外未回余料进入差异。 |
| 质检与交货 | 合格数量进入成品库，返工件与新完工分别跟踪；交付批次可回溯到投入批次。 | 问题原料批次可列出受影响成品和客户。 |
| 成本与业财 | 归集领料、人工、制造费用与委外费，凭证分币种平衡；锁期后追加调整。 | 跨法人往来单边缺失时阻止关期。 |

## 失联、中断及恢复

过账锁定期间与批次余额，领退料、工单用量和成本来源关联在同一事务提交；期间关闭后以调整凭证更正。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

标准工时与实际工时独立归集；工单关闭前列出未退余料、在制成本、未匹配委外费用。 净缺 100 件，替代造成材料成本增加 20 元。销售交付可追到成品和投入批次，未放行数量不计可交。
