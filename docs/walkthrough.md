# 演示操作与异常复现

按 [快速开始](../README.md#快速开始) 从空库启动并导入演示。登录后选「澄岳精工制造」账套。演示日期固定为 2037 年 6 月，所有数量、批次与往来单位均为合成数据。

| 入口 | 核对方法 |
| --- | --- |
| 组织与审计、主数据 | 查看装配车间、检测车间和集团物料 `DEVICE`、`PIN`、`PIN-R`，核对制造法人的标准价和供应策略。切换「澄岳贸易」后查看独立的组织物料和库位。 |
| 销售与交付 | 打开销售单 `SO-DEVICE-100`，核对需求 100 台、已出库 98 台，以及仍待交付的数量。 |
| BOM 与工艺 | 打开 `DEVICE` 的生效 BOM，确认每台用 2 件 `PIN`，检查加强定位销替代料及 `MODULE` 的下层 BOM。生产工单详情保留当时选用的 BOM 和工艺版本。 |
| 物料计划 | 从首页打开试算快照。`PIN` 需求 200 件，扣除已可用 70 件和按期在途 30 件后缺 100 件。 |
| 采购与仓储 | 查看 `PO-INCOMING-30`、收货 `RC-INCOMING` 和批号 `PIN-INCOMING-30`，核对采购、收货和库存流水。 |
| 车间与委外 | 从首页打开 `WO-DEVICE-100`，查看工序时段、实绩和领料行；委外单的单独操作见下文。 |
| 质检与交货 | 打开关联返工单，确认 2 台尚未放行。从 `PIN-R-10` 向下游追溯，核对成品批次、`SHIP-DEVICE-98` 和客户，下载追溯 CSV。 |
| 财务与月结 | 工单材料差异为 20 元。核对 `AP-PIN-INVOICE`、发货形成的应收及凭证，金额分别为 1,560 元和 6,370 元。 |

## 超额发料、委外留存与结案

在独立演示账套以管理员执行。日期可使用连续三天，下面称第一、第二、第三天。发料、产出、退料和发票的过账日期按发生顺序填写。

1. 从主数据建立委外成品 `TREATED` 和采购毛坯 `METAL`，基本单位均为「件」。准备一个库位和一家供应商。发布 `TREATED` 的 BOM，自第一天起每件成品耗用 2 件 `METAL`。从批次库存向该库位登记 `METAL` 期初批次 `BLANK-25`，数量 25，单位成本 10 元。
2. 新建并批准委外工单 `WO-VENDOR`，生产 10 件 `TREATED`，计划开工日为第一天。关联委外加工单，填写单位加工费 3 元，合同日为第一天，再下达工单。
3. 在加工单提交「向加工方发料」，尝试发出 25 件 `BLANK-25`，超额批准号留空。系统拒绝，库位仍为 25 件。到关联工单为 `METAL` 补录 5 件超额领料授权，再用该批准号发出 25 件。加工方物料留存为 25 件。
4. 第二天登记 10 件委外产出，从原发料批次填实际耗用 20 件。工单的产出进入待检并在质量页放行 10 件。尝试结案，待解决事项分别显示加工方留存 5 件和未匹配加工费 30 元。留存事项指向原发料记录。
5. 第三天在加工单收回 4 件余料，登记 1 件委外损耗。库位恢复 4 件，加工方留存结清。匹配加工费发票 29 元，确认 1 元价差，再到工单完成结案。

## 自动复核

在独立测试实例运行以下命令。`ERP_TEST_DATABASE=1` 表示指定数据库可写入测试夹具。回归会新建合成组织和单据，请使用开发或演示实例。

```sh
docker compose stop worker
docker compose cp tests web:/srv/erp/tests
docker compose exec -T -e ERP_TEST_DATABASE=1 web php tests/workshop.php
docker compose exec -T -e ERP_TEST_DATABASE=1 web php tests/subcontract.php
docker compose start worker
```

`workshop.php` 另复核了车间按批次领料时的超额授权和重复提交。`subcontract.php` 核对发料回执、五件留存、仓库数量、批次谱系和加工费差异。相同的发料请求标识应返回原发料记录号，五件授权仍只消耗一次。[验收用例和结果](validation/README.md)

收货提交后遇到网络中断时，用原账号和原账套在 `?page=receipt&operation=purchase.receive&request_key=原请求标识` 查回收货单号，再打开采购单核对收货批次。收到原回执后仍可用相同标识和内容重试。`http-workspace.php` 复现客户端断开、按标识查回和原样重试，检查采购单仅有一张有效收货单。[回执接口](architecture.md)
